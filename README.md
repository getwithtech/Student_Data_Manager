# Student Data Manager

A simple C++ command-line application to manage student data. It allows you to add students, view them, and persist the data to a text file.

## Project Structure
```text
Student-Data-Manager/
├── main.cpp
├── student.h
├── student.cpp
├── file_handler.h
├── file_handler.cpp
├── data.txt
└── README.md
```

## How to Compile
You can compile the project using `g++` (or any modern C++ compiler):

```bash
g++ main.cpp student.cpp file_handler.cpp -o student_manager
```

## How to Run

```bash
./student_manager
```
